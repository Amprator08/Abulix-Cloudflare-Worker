## 🌟 دربارهٔ Abulix

**Abulix Panel** یک پنل تحت وب با رابط کاربری فارسی و طراحی مدرن است که برای اجرا در محیط **Cloudflare Workers** آماده شده است. این پروژه از پایگاه دادهٔ **Cloudflare D1** برای بخش‌هایی از داده‌های پنل استفاده می‌کند و مسیرهای جداگانه‌ای برای پنل، صفحهٔ کاربر و لینک اشتراک دارد.

هدف Abulix، ارائهٔ تجربه‌ای ساده‌تر برای مدیریت و دسترسی به امکانات پنل، با رابطی مناسب موبایل و دسکتاپ است. 💫

## ✨ قابلیت‌ها

- 🎨 **رابط کاربری اختصاصی Abulix** با هویت بصری آبی و زرد
- 📱 **طراحی واکنش‌گرا** برای نمایش در موبایل، تبلت و دسکتاپ
- ☁️ **اجرا روی Cloudflare Workers** بدون نیاز به مدیریت یک سرور وب سنتی
- 🗄️ **پشتیبانی از Cloudflare D1** از طریق Binding با نام `DB`
- 🧭 **مسیرهای مجزای پنل، کاربر و اشتراک** برای دسترسی بخش‌بندی‌شده
- 🔗 **صفحه و لینک اشتراک (Subscription)** برای دسترسی به اطلاعات اشتراک
- 👤 **صفحهٔ کاربر** در مسیر `/user`
- 🛠️ **صفحهٔ پنل** در مسیر `/panel`
- 📡 **پشتیبانی از ارتباطات مبتنی بر Cloudflare Sockets** در کد Worker
- 🧩 **ساختار تک‌فایلی Worker** برای ساده‌ترشدن استقرار و نگهداری
- 🌀 **مبهم‌سازی کد اجرایی** برای دشوارترشدن خواندن مستقیم سورس در نسخهٔ توزیع‌شده
- 📣 **پیوند کانال Abulix** برای دنبال‌کردن اطلاعیه‌ها و به‌روزرسانی‌ها

> توجه: امکاناتی که به تنظیمات حساب Cloudflare، Binding دیتابیس یا پیکربندی محیط اجرا وابسته‌اند، پس از تنظیم صحیح محیط در دسترس خواهند بود. فهرست بالا بر اساس ساختار و تنظیمات شناخته‌شدهٔ نسخهٔ فعلی نوشته شده است؛ جزئیات هر قابلیت ممکن است با نسخه‌های بعدی تغییر کند.

## ☁️ پیش‌نیازها

برای استقرار نسخهٔ فعلی، این موارد را آماده کنید:

- حساب فعال **Cloudflare**
- یک **Cloudflare Worker**
- یک پایگاه دادهٔ **Cloudflare D1**
- تعریف Binding دیتابیس با نام دقیق `DB`

### 🔧 تنظیم Binding دیتابیس

1. وارد داشبورد Cloudflare شوید.
2. بخش **Workers & Pages** را باز کنید و Worker موردنظر را انتخاب کنید.
3. به بخش **Settings** و سپس **Bindings** بروید.
4. یک Binding از نوع **D1 database** اضافه کنید.
5. نام متغیر را دقیقاً `DB` قرار دهید و دیتابیس موردنظر را انتخاب کنید.
6. تغییرات را ذخیره و Worker را دوباره Deploy کنید.

## 🚀 استقرار

1. فایل Worker پروژه را در محیط Cloudflare بارگذاری کنید.
2. Binding دیتابیس D1 با نام `DB` را تنظیم کنید.
3. تنظیمات لازم برای نسخهٔ مورد استفاده را بررسی کنید.
4. Worker را Deploy کنید.
5. آدرس Worker را باز کنید و مسیرهای موردنیاز پنل را بررسی کنید.

> ⚠️ صرفاً Deploy شدن Worker به معنی آماده‌بودن کامل پنل نیست؛ Bindingها و تنظیمات موردنیاز باید صحیح باشند. قبل از استفادهٔ واقعی، مسیرهای پنل و اشتراک را آزمایش کنید.
